# JBL headphones website

Headphones landing page from Bedimcode video tutorial, built with HTML, CSS, and JavaScript. Responsive layout and SwiperJS animations.

Video tutorial from Bedimcode https://www.youtube.com/watch?v=BIXsjKxPo8o&feature=youtu.be

## Tech Stack

- HTML5 – Semantic markup.
- CSS3 – Flexbox, Grid, animations, media queries.
- JavaScript – Interactive elements.
- Vercel – Instant deployment and hosting.
